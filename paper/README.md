# Paper Companion Materials

This directory contains the reproducibility figures, generated tables, and
their build sources. Numerical tables are generated from the canonical CSV
files under `results/`; do not edit their values manually.

The authoritative Scientific Reports manuscript is maintained separately in
the journal's required DOCX format. Manuscript drafts, compiled PDFs, and
journal-submission working packages are local artifacts and are intentionally
excluded from Git. Repository figures and tables remain auditable public build
materials, but the repository is not a complete archival deposit of the
processed corpus tensor or neural checkpoints.

See `docs/RESULTS_PROVENANCE.md` for the allowed evidence family and
`docs/DATA_AVAILABILITY.md` for the current peer-review statement.
