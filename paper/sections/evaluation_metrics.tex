\section{Evaluation Metrics}

Evaluation is split between sequence-model behavior and post-tonal constraint behavior. Token accuracy and cross-entropy loss are reported for trained Transformer checkpoints on the held-out split. Constraint metrics are computed from decoded or rule-generated symbolic events: target pc-set coverage, interval-vector distance, row-order accuracy, aggregate completion rate, serial transformation accuracy, rhythmic-profile distance, density-curve error, gesture consistency score, range violation rate, and MusicXML export success rate.

MusicXML export success requires the file to be written and structurally parsed as a score-level MusicXML document. Human expert evaluation uses blind 1--7 ratings for material coherence, pc-set consistency, serial logic clarity, rhythmic control, gesture recognizability, notational usefulness, and usefulness for contemporary composition sketching.
