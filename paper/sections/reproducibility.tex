\section{Reproducibility Statement}

All default data are generated from deterministic scripts and fixed seeds. No copyrighted contemporary scores are bundled, scraped, or required. The CPU smoke command is \texttt{.\textbackslash scripts\textbackslash run\_project2\_all\_experiments.ps1}. The full local command for an RTX 4060 Ti 16GB system is \texttt{.\textbackslash scripts\textbackslash run\_project2\_full\_local.ps1}. The scripts write aggregate metrics to \texttt{results/project2\_metrics.csv}, constraint metrics to \texttt{results/project2\_constraints.csv}, generation metadata to \texttt{results/project2\_generation\_examples.json}, and LaTeX tables to \texttt{paper/tables/}.
