\section{Reproducibility Statement}
\label{sec:reproducibility}

All bundled data are generated from source code and fixed seeds. No copyrighted post-1945 score is downloaded or required. The processed corpus is stored as \path{data/processed/project2_v3_main.pt}; its explicit 20,000/2,000/2,000 split and SHA-256 digest are recorded in \path{results/project2_full_split_summary.json}. The split records seed 42, \texttt{smoke=false}, and zero discarded score-body tokens under the coverage-cycle training strategy.

On Windows, \path{scripts/smoke_project2.ps1} runs the isolated CPU verification workflow, while \path{scripts/run_project2_full_local.ps1 -Resume} runs and audits the CUDA matrix. The completed formal environment used Python 3.11.9, PyTorch 2.5.1+cu121, CUDA, and an NVIDIA GeForce RTX 4060 Ti. Peak measured process RAM was 4.637GiB and peak allocated CUDA memory was 0.667GiB. No out-of-memory adjustment occurred.

Every neural training directory contains a best checkpoint, a resumable last checkpoint, and a summary with optimizer state, scaler state, random-number state, epoch history, best epoch, configuration hash, corpus hash, elapsed time, and resource peaks. All neural rows reached 60 epochs. A single Windows CUDA-driver startup fault occurred before \texttt{pcset\_only} training; the logged health check and resumed run completed that configuration without changing its data or settings. The incident is retained in \path{results/project2_full_run_incidents.json}.

Canonical aggregate outputs are \path{results/project2_metrics.csv}, \path{results/project2_constraints.csv}, and \path{results/project2_generation_examples.json}. The complete command history, checkpoint hashes, completed configurations, environment audit, and artifact gates are in \path{results/project2_full_run_report.md}. Manuscript tables are generated from the canonical CSV files, and Figure~\ref{fig:full-results} has a saved source CSV and build script under \path{paper/figures/}. The twenty-example expert package and its manifest are under \path{expert_eval/project2/}.

The experiment-completion revision is recorded in the full-run report; the present manuscript revision adds no new experimental values. The source repository location is given on the title page for the identified manuscript. Because the repository is private during review and large tensors and checkpoints may be excluded from version control, an archival release must include code, configurations, hashes, metric files, tables, representative MusicXML, and regeneration instructions.
