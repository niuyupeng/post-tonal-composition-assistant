\section{Reproducibility Statement}
\label{sec:reproducibility}

All bundled training data are generated from source code and fixed seeds; no copyrighted post-1945 score is downloaded or required. The full split and seed are recorded in \path{results/project2_full_split_summary.json}. Large processed tensors and checkpoints are excluded from version control, but the scripts and configuration files needed to regenerate them are retained.

On Windows, the CPU engineering check is executed with \path{scripts/smoke_project2.ps1}. The complete local CUDA pipeline is executed with \path{scripts/run_project2_full_local.ps1} in a Python 3.11 environment. Configuration files record architecture, optimizer, split sizes, fp16 use, early stopping, and the Windows-safe worker count.

Aggregate metrics are stored in \path{results/project2_metrics.csv} and \path{results/project2_constraints.csv}. Controlled metrics and per-sample reports use the \path{project2_controlled} prefix. Generated examples are paired with JSON analysis reports under \path{expert_eval/project2/}. Tables are created from CSV/JSON outputs rather than transcribed manually.

The independent-seed configs are stored under \path{configs/} and carry the suffixes \texttt{seed42}, \texttt{seed43}, and \texttt{seed44}. Per-seed rows and aggregate statistics are stored under \path{results/} as \path{project2_multiseed_training_metrics.csv} and \path{project2_multiseed_training_summary.json}. The table is regenerated by \path{post_tonal.analyze_multiseed_training}. This command verifies epoch histories, aligned 2,000-item test sizes, checkpoint hashes, and effective batch settings before writing outputs.

The controlled replication is executed by \path{scripts/run_project2_multiseed_controlled.ps1}. Raw K=1 and K=4 records are stored under \path{results/multiseed_controlled/}. Before aggregation, the runner verifies the 2,000-item count, per-item seed schedule, candidate count, generation batch size, sampling protocol, finite endpoint values, and first-candidate SHA-256 identity for every checkpoint. Cross-checkpoint statistics are written to \path{results/project2_multiseed_controlled_statistics.json} and \path{results/project2_multiseed_controlled_statistics.csv}; the corresponding table is generated at \path{paper/tables/project2_multiseed_controlled_results.tex}.
