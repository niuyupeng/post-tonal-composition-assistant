# Data Availability

## Manuscript Data-Availability Statement

> The datasets generated and/or analysed during the current study, together
> with the source code and materials required to regenerate the synthetic
> corpus and reproduce the reported analyses, are publicly available in the
> Post-Tonal Composition Assistant GitHub repository,
> https://github.com/niuyupeng/post-tonal-composition-assistant.

This wording uses the journal's public-repository form and should be entered
identically in the manuscript and submission system. The public repository
contains the supporting result data and deterministic regeneration materials.
The complete 24,000-sample processed corpus, tokenizer vocabulary, and twelve
best neural checkpoints are published as assets of the `v1.0.0`
reproducibility release:

> https://github.com/niuyupeng/post-tonal-composition-assistant/releases/tag/v1.0.0

## What Exists

- Source code, configurations, tests, build scripts, canonical aggregate
  CSV/JSON files, provenance reports, and representative MusicXML examples are
  versioned in this repository.
- The synthetic corpus is generated by the repository's rules and fixed seed;
  no copyrighted contemporary score corpus is used.
- The processed 24,000-fragment tensor, tokenizer vocabulary, and twelve best
  neural checkpoints are distributed as release assets because they exceed
  practical source-control size limits. SHA-256 checksums accompany the assets.
- No human expert ratings or independent user-provided validation scores are
  represented as collected data.

## Reproduction Route

The public repository documents the fixed seed, explicit split membership,
configuration files, commands, and hashes used for the reported run. Running
the documented corpus-generation pipeline reconstructs the complete synthetic
corpus without copyrighted score data.
