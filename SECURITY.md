# Security Policy

This research software is not designed for safety-critical or real-time use.
Please report suspected credential exposure, unsafe file handling, dependency
vulnerabilities, or arbitrary-code execution privately to the repository
owner through GitHub rather than opening a public issue.

Only the current `main` branch is maintained. Generated MusicXML and JSON files
should be treated as untrusted input when supplied by third parties. Do not
commit secrets, access tokens, private submission correspondence, identifiable
expert-rating data, or copyrighted validation scores.
