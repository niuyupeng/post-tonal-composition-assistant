# Results

The `project2_*` canonical files listed in
`docs/RESULTS_PROVENANCE.md` support the current automatic-results claims.
They were produced by the completed 20,000/2,000/2,000 full run and must not be
replaced by smoke or partial outputs.

Large processed corpora, checkpoints, raw per-sample development records, and
per-configuration MusicXML export directories are excluded from Git. The full
run report records commands, hashes, environment details, and completion gates.

Historical controlled-decoding and multi-seed aggregate files, when present,
are secondary development records and are not the canonical evidence family.
